1. 零基础本地部署大模型：8G 显存跑通 DeepSeek

想在自己的电脑上免费、离线、私有地运行 AI？本教程带你从零开始。

· 第一步：Windows 按 Ctrl+Shift+Esc 打开任务管理器 → 性能 → GPU → 看「专用 GPU 内存」，记下你的显存大小

· 第二步：访问 ollama.com 下载安装 Ollama（傻瓜工具，一路下一步）

· 第三步：打开命令行（Win+R 输入 cmd），输入 ollama pull qwen2.5:14b 下载模型

· 第四步：输入 ollama run qwen2.5:14b 开始对话

· 显存对照：8G 用 14b，6G 用 7b，4G 用 3b，没有独显用 1.5b

· ⚠️ 8G 显存务必设 OLLAMA_CONTEXT_LENGTH=8192，设 16384 会爆显存

2. AI 绘画入门：从提示词到出图

用即梦（jimeng.jianying.com）或 Midjourney，输入描述就能生成图片。

· 提示词公式：主体 + 风格 + 光线 + 构图 + 画质

· 示例：「一只橘猫，赛博朋克风格，霓虹灯光，特写镜头，电影感，8K 高清」

· 技巧：描述越具体效果越好，参考提示词库页面的模板

· 多尝试不同风格词，找到自己喜欢的画风
